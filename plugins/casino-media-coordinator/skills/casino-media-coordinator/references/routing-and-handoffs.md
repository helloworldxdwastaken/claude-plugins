## Select branches deliberately

- Direct TTS from checked text is not original-performance conversion. In this repo the latest direct-Fish workflow is documented in `audio/fish-scenes/README.md` and the current root README. Use the `casino-voice-cloner` direct Fish branch and its `references/fish-scene-workflow.md` when the user requests it; give the audio worker the actual skill and current project recipe. Unknown source words remain pending. Supplied-script takes use the supplied words and do not imply source-performance fidelity.
- A finished review pair, quiet wheel export or reference-only picture is not a game-admitted scene. Integration needs authoritative result and source-window eligibility independent of cosmetic acceptance.
- Mapping preparation can proceed before a generation budget or provider upload is authorized. A private quote may itself upload inputs; confirm the route's actual effects within existing authorization.
- If only a prop should change, preserve the original actress and room. If only timing is requested, do not add character generation. Inspector-only requests produce evidence/repairs, not automatic regeneration.

## Dependency invalidation

New source/crop/trim/cut changes can affect picture mapping, speech sample placement, gesture/lip review, cue scheduling and result-window admission. A voice/text change affects word/identity/level checks, duration and all affected AV/admission windows. A new output encoding changes artifact identity and may change presentation timestamps; verify final delivered variants separately. A changed room/face authority invalidates its appearance reviews across dependent shots.

Save the reason for each invalidation and the exact downstream versions requiring recheck. Keep valid unaffected evidence; accepted historical assets need no duplicate owner approval solely because another shot changed.
