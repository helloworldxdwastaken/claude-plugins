# Fine-detail comparison

Review the output against target appearance images, and separately against source performance. Do not penalize an intended replacement for differing from the original actor or room.

## Coverage

Probe the whole decoded file and watch every shot at normal speed. Extract source/output paired frames using the recorded PTS mapping, plus target reference images. Include the first and last actual frames; both sides of every camera cut; starts/middles/ends of each shot; maximum face turns, blinks, hand contact, foreground crossings and reflection changes. Inspect every frame in short problem intervals, appearance ramps and seams. For longer material, record sampled times and dense-review intervals honestly; sparse samples never certify all frames.

For an established set, place the actual accepted beginning/earlier shots beside the candidate and its neighbors. Identify camera family/axis and trace the visible wall panels, windows/doors, lamps, furniture and floor through the cuts. A plausible room in matching colors still fails if it invents furniture, moves landmarks or uses the wrong side of the set. Record room and camera findings separately from identity; hold unresolved mismatches before expanding the batch.

Use native-resolution crops for face, garment details, hands and distant set landmarks. Upsized review crops reveal pixels but add no source detail. Avoid whole-frame pixel similarity as an acceptance score when replacement intentionally changes pixels.

## Review dimensions

| Area | Compare against the relevant authority |
| --- | --- |
| Identity | Face shape/proportions, eye spacing/color, brows, nose, lips, ears, age cues, skin marks, makeup, hairline/style/parting; identity during profile, speech, blinks and reappearance |
| Clothing | Exact silhouette/color under scene lighting, textile sheen/weave, collar/neckline, seam paths, pockets, button count/placement, cuff shape/fasteners, sleeve length, prints/embroidery/logos and accessories; details remain attached during movement |
| Hands/body | Manicure, finger count, anatomy, body scale, seated/standing posture, chair and seat height, sleeve continuity, contact with props/table and correct foreground occlusion |
| Environment | Relative window/door/curtain/lamp/furniture positions, flooring/rug, table shape/orientation, equipment design/scale, camera perspective, light direction, contact shadows and reflections; no mirrored or invented layout between angles |
| Objects | Presence/count, shape/material, labels/printed features where legible, motion/contact and disappearance/reappearance; no duplicates or floating props |
| Temporal behavior | Source shot order, cut times, camera path/crop, gesture starts/contact/releases, head turns, posture, first-frame appearance ramps, end truncation, flicker, texture crawl and seam jumps |
| Speech picture | Mouth articulation against the actual final speech, jaw/teeth/tongue artifacts, lip closure/onsets, pauses and expression; timestamps or mouth-opening curves alone do not prove phoneme sync |

For casino scenes, separately inspect ball count, wheel pocket order/colors/numerals, stationary versus moving parts, printed felt and source HUD/result overlays. Photoreal generated numbers are not verified game geometry. Recorded source outcomes never override the committed game result.

## Evidence and acceptance

Write one row per meaningful mismatch: output time/frame; source time/frame; category; expected reference detail; observed difference; evidence path; repair; remaining status. Reuse valid previous owner approvals for unchanged artifacts. Describe any explicitly accepted cosmetic deviation without erasing its existence.

Use statuses such as inspected/pass, mismatch, not visible, and not assessed. Report technical decode/timeline checks separately from visual continuity and heard/perceived lip sync. A folder of extracted frames is preparation until someone actually inspects it.
